2. Purpose of the Project

KanMind is a non-commercial learning and portfolio project developed as part of the Developer Akademie Backend curriculum.

Personal data is processed only to provide and demonstrate the functionality of the KanMind application.

3. Data Processed

When using KanMind, the following personal data may be processed:

  • Full name
  • Email address
  • User account identifier
  • Authentication token
  • Password in protected, hashed form on the backend
  • Board ownership and memberships
  • Tasks created, assigned or reviewed
  • Task comments

4. Registration and Authentication

A full name, email address and password are required when creating a KanMind user account.

The password is processed by the Django backend and stored in hashed form. Plain-text passwords are not stored in the application database.

After successful registration or login, an authentication token is used to identify authenticated API requests.

The processing is necessary to provide the user account and authentication functionality requested by the user.

5. Local Storage

KanMind uses the browser's local storage to keep the authenticated session available between page changes.

The following information is stored locally in the browser:

  • Authentication token
  • User ID
  • Email address
  • Full name

This information is required for authentication and for displaying user-specific application content.

The stored authentication information is removed from local storage when the user logs out.

6. Boards, Tasks and Comments

When using the application, information relating to boards, tasks and comments is stored in the backend database.

This can include board ownership, board membership, task assignments, reviewers and comments written by authenticated users.

This processing is necessary to provide the core functionality of the KanMind application.

7. Legal Basis

Personal data required to provide an account and the requested application functionality is processed on the basis of Article 6(1)(b) GDPR where applicable.

Processing necessary for the operation, security and technical testing of this non-commercial portfolio project may additionally be based on Article 6(1)(f) GDPR.

8. Data Retention

Personal data is stored only for as long as it is required for the operation and demonstration of the application.

Data may be deleted when it is no longer required or when a justified deletion request is made, provided that no legal obligation requires further storage.

Requests regarding stored personal data can be sent to the email address listed above.

9. Hosting

At the current development stage, KanMind is primarily used in a local development environment.

Before the project is made publicly available on a hosting platform, this privacy policy will be updated to include information about the hosting provider, server log files and any additional technical data processing.

10. Third Parties and Tracking

KanMind does not intentionally use advertising services, analytics tools or profiling for the current learning project.

Personal application data is not sold to third parties.
